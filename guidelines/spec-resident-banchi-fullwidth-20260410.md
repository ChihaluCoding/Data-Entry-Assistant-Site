# 仕様書: 住民票モード番地入力の全角化（2026-04-10）

## 背景
- 現在の番地正規化では、基本モードと住民票モードの両方で番地が半角化される。
- 住民票モードでは、半角で入力しても番地を全角表記で扱いたい要望がある。

## スコープ
- 住民票モードの `departBanchi` と `registryBanchi` 入力時に、半角英数字・半角英字・半角ハイフンを全角へ正規化する。
- 保存状態や復元データから住民票モードの番地を読み込む際も、同じ全角正規化を適用する。

## 制約
- 基本モードの `banchi` は従来どおり半角正規化のままとする。
- 住民票モードの番地以外の項目は変更しない。
- 番地の記号統一ルールは維持し、ハイフン相当は全角 `－` に統一する。

## 受け入れ基準
- 住民票モードの番地欄で `1-2` と入力すると、表示値は `１－２` になる。
- 住民票モードの番地欄で `A-12` と入力すると、表示値は `Ａ－１２` になる。
- 保存済みデータに半角番地が残っていても、住民票モードで復元後は全角表記になる。
- 基本モードの番地欄は従来どおり半角表記のまま。

## 非スコープ
- 基本モード番地の仕様変更
- 建物名や氏名など他項目の文字種変換仕様変更
