# 仕様書: 書き込みショートカット追加後の白画面修正（2026-04-11）

## 背景
- `Command/Ctrl + W` 対応後、`DataEntryForm` の `useEffect` 依存配列に未定義の識別子が残り、初回レンダリングで白画面になった。

## スコープ
- 未定義参照を取り除き、初回レンダリングでクラッシュしないようにする。
- 再発防止として、該当識別子がコンポーネント内に残っていないことを確認する回帰テストを追加する。

## 受け入れ基準
- アプリ起動時に白画面にならず、フォームが表示される。
- `selectedSheetIdByMode` 参照が `DataEntryForm.tsx` に存在しない。

## 非スコープ
- 書き込みショートカット仕様そのものの変更
