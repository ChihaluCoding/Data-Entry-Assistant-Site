# 仕様書: Command/Ctrl + W で書き込み実行（2026-04-11）

## 背景
- 入力完了後にキーボードだけでシート書き込みまで完了したい。
- 既存UIには `書き込み` と保存済みリスト向けの `上書き書き込み` があるが、ショートカット起点がない。

## スコープ
- 基本モードと住民票モードで `Command/Ctrl + W` に通常の `書き込み` を割り当てる。
- 基本モードと住民票シート1で、編集中の保存済みリスト項目がある場合のみ `Command/Ctrl + Shift + W` に `上書き書き込み` を割り当てる。
- Windows/Linux の `Ctrl + W` と macOS の `Command + W` の両方を受け付ける。

## 制約
- ブラウザ標準のタブを閉じる挙動は `preventDefault()` で抑止する。
- `Alt + W` は対象外とする。
- 住民票シート2では既存仕様どおり一覧上書き対象がないため、`Command/Ctrl + Shift + W` は通常上書きに変換しない。

## 受け入れ基準
- `Command/Ctrl + W` で現在モードの通常 `書き込み` と同じ処理が実行される。
- 基本モードで保存済みリスト編集中に `Command/Ctrl + Shift + W` を押すと、現在フォーム内容で元行上書き書き込みされる。
- 住民票シート1で保存済みリスト編集中に `Command/Ctrl + Shift + W` を押すと、現在フォーム内容で元行上書き書き込みされる。
- 上書き対象がない状態で `Command/Ctrl + Shift + W` を押した場合は、何が足りないか分かるエラーが表示される。

## 非スコープ
- Apps Script 側のWebhook仕様変更
- 既存ボタン文言や配置変更
