# 建物名の数字幅維持仕様

## タスク概要
- 建物名欄で数字を入力したとき、半角へ自動変換しない。
- 英字の全角化は従来どおり維持する。

## 対象
- `src/app/components/DataEntryForm.tsx`
- `scripts/test-building-normalization.mjs`

## 要件
1. 建物名の `０-９` はそのまま維持する。
2. 建物名の `0-9` もそのまま維持する。
3. 半角英字 `A-Za-z` は従来どおり全角英字へ変換する。
4. 建物名のその他文字は変更しない。

## 期待例
- `１０１` → `１０１`
- `101` → `101`
- `A101` → `Ａ101`
- `Ａ101` → `Ａ101`
