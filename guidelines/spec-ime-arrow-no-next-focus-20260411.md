# 仕様書: IME候補選択中の↑↓で次入力へ進まない（2026-04-11）

## 背景
- 日本語入力中に IME 候補を `↑` / `↓` で選ぶ際、フォーム全体の上下ナビゲーションが反応して別の入力欄へ移動してしまう。
- Enter だけ抑止しても、候補移動用の `↑` / `↓` が漏れていると入力継続ができない。

## スコープ
- 基本モードと住民票モードのフォームで、IME 候補選択中の `↑` / `↓` をフォーカス移動対象から除外する。
- IME候補確定に使う `Enter` の抑止は継続する。
- アプリ内の住所候補リストに対する `↑` / `↓` 操作は既存どおり維持する。

## 制約
- IME未使用時の通常の `↑` / `↓` ナビゲーションは維持する。
- 候補リスト表示中の `handleSuggestionKeyDown` の挙動は変更しない。

## 受け入れ基準
- IME変換中に `↑` を押しても前の入力欄へ移動しない。
- IME変換中に `↓` を押しても次の入力欄へ移動しない。
- IME未使用時の `↑` / `↓` は既存どおり前後項目移動できる。
- 住所候補リスト表示中の `↑` / `↓` による候補移動は維持される。

## 非スコープ
- 入力順やフォーカス順自体の変更
- IME以外のキーボードショートカット変更
