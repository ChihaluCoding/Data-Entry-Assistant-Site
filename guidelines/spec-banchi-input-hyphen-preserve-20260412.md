# 番地入力中のハイフン保持仕様

## タスク概要
- 番地欄で `-` を入力しても、その場で消えないようにする。
- 入力中は `-` `ー` `―` などのダッシュ類を `－` へ統一しつつ保持する。
- 入力確定時のみ、先頭末尾の余分な `－` を除去する。

## 対象
- `src/app/lib/banchiNormalization.js`
- `src/app/components/DataEntryForm.tsx`
- `scripts/test-banchi-normalization.mjs`

## 要件
1. `onChange` 中の番地入力では、単独の `-` も `－` として表示される。
2. `12-` のような末尾ハイフンも入力途中では保持する。
3. `onBlur` 時には、余分な先頭末尾 `－` を除去して最終形へ寄せる。
4. 漢字・ひらがな・ダッシュ類の `－` 正規化ルールは維持する。

## 期待例
- 入力中 `-` → `－`
- 入力中 `12-` → `12－`
- フォーカス離脱後 `12－` → `12`
