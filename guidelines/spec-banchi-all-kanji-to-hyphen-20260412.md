# 番地入力の全漢字ハイフン化仕様

## タスク概要
- 番地入力欄では、`丁目` `番地` `番` `号` だけでなく、それ以外の漢字もすべて `－` に正規化する。
- `-` `ー` `―` など、`－` 以外のダッシュ類が入力された場合も `－` に自動変換する。

## 対象
- `src/app/lib/banchiNormalization.js`
- `scripts/test-banchi-normalization.mjs`
- `scripts/regression-banchi-halfwidth.mjs`

## 要件
1. 番地の正規化では、英数字の全角・半角変換ルールは既存どおり維持する。
2. ひらがな区切り語 `ちょうめ` `ばんち` `ばん` `ごう` は `－` に変換する。
3. 任意の漢字は区切り扱いとして `－` に変換する。
4. `-` `‐` `‑` `‒` `–` `—` `―` `ｰ` `ー` `－` はすべて `－` に統一する。
5. 連続した `－` は1つにまとめ、先頭末尾の `－` は除去する。

## 期待例
- `3丁目42番19－50` → `3－42－19－50`
- `3甲42乙19丙50` → `3－42－19－50`
- `3ちょうめ42ばん19ごう` → `3－42－19`
- `1―2` → `1－2`
