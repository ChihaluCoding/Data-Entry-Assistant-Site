# 仕様書: 番地の漢字区切りをハイフンへ統一（2026-04-11）

## 背景
- 番地欄に `3丁目42番19－50` のような入力をした場合、`丁目` や `番` がそのまま残る。
- 番地は区切りをハイフンで統一したい。

## スコープ
- 基本モードの `banchi` と、住民票モードの `departBanchi` / `registryBanchi` で、`丁目` / `番地` / `番` / `号` をハイフンへ正規化する。
- 数字・英字の文字幅は既存どおり維持し、区切り記号は全角 `－` に統一する。
- ひらがなの `ちょうめ` / `ばんち` / `ばん` / `ごう` も同様に区切り記号として扱う。

## 制約
- 漢字区切り以外の番地正規化ルールは維持する。
- 建物名や他項目の正規化は変更しない。

## 受け入れ基準
- 基本モードで `3丁目42番19－50` は `3－42－19－50` として保持される。
- 住民票モードで `3丁目42番19－50` は `３－４２－１９－５０` として保持される。
- `1番地` のような入力も末尾に余分なハイフンを残さない。

## 非スコープ
- 住所欄全体の漢字表記変換
