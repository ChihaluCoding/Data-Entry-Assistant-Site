# 仕様書: 住民票シート1 フォルダ書き込みで C:E 既存値を再利用（2026-04-10）

## 背景
- 住民票シート1のフォルダ書き込みは、現在 `C:E` がすべて空の先頭行からしか書けない。
- そのため、`C:E` にだけ既存値が残っている行があっても再利用されず、完全空行へ追記されてしまう。

## スコープ
- `appendResidentFolderRows` の行選定を変更し、`C:E` に既存値があっても、他列が空ならその行へ再書き込みできるようにする。
- 複数行一括書き込みでは、必要件数ぶん連続して「他列が空」の行ブロックを探してそこへ書き込む。

## 制約
- `C:E` 以外の列に値がある行は、従来どおり使用しない。
- 書き込み列は引き続き `C:D:E` 固定とする。
- 住民票シート2や通常の住民票書き込みロジックは変更しない。

## 受け入れ基準
- `C:E` に既存値があり、他列が空の行があれば、フォルダ書き込みはその行から上書きできる。
- `A/B/F` など `C:E` 以外に値がある行は、従来どおり飛ばして次の候補行を探す。
- 必要件数ぶんの連続行が確保できない場合は、末尾へ追記される。

## 非スコープ
- シート列マッピングの変更
- 住民票シート2の B/C 列ロジック変更
- UI 文言や操作フローの変更
