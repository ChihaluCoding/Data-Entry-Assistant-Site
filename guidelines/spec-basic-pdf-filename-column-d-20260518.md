# 基本モード PDFファイル名D列書き込み仕様（2026-05-18）

## スコープ
- 基本モードのシート書き込み時、PDFが読み込まれている場合はD列へ読み込み中PDFのファイル名を送信する。
- PDF未読込時は既存のD列マッピングを維持する。
- リロード時のPDF表示保持が有効な場合、PDF本体と一緒にファイル名も復元する。

## 制約
- Google Sheets Webhookのaction名、レスポンス形式、A〜J列の送信形式は変更しない。
- 住民票モードの書き込み列マッピングは変更しない。
- 新しい外部サービスや有料APIは使わない。

## 受け入れ条件
- PDFを読み込んだ状態で基本モードの書き込みを行うと、payloadの`values.D`が読み込み中PDFのファイル名になる。
- PDF未読込の場合は、基本シート1では従来の結合住所、基本シート2では従来の氏名がD列へ送られる。
- PDF表示保持の復元後も、保存されているPDFファイル名をD列へ送れる。
- `npm run build` と追加テストが成功する。

## 非スコープ
- 住民票モードのD列変更。
- Google Apps Script側のデプロイや権限設定変更。
