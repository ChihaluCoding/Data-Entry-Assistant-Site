# 仕様書: 番地のひらがな区切りもハイフンへ統一（2026-04-11）

## 背景
- 番地欄では漢字の `丁目` / `番` / `号` を `－` へ統一している。
- ひらがなの `ちょうめ` / `ばんち` / `ばん` / `ごう` でも同じように区切りとして扱いたい。

## スコープ
- 基本モードと住民票モードの番地正規化で、漢字だけでなく、ひらがなの `ちょうめ` / `ばんち` / `ばん` / `ごう` も `－` に変換する。

## 受け入れ基準
- 基本モードで `3ちょうめ42ばん19ごう` は `3－42－19` になる。
- 住民票モードで `3ちょうめ42ばん19ごう` は `３－４２－１９` になる。
- `1ばんち` は余分な末尾記号を残さず `1` になる。
