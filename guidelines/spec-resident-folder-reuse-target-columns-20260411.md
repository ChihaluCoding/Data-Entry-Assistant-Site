# 仕様書: 住民票フォルダ書き込みで対象列既存値の行を再利用する（2026-04-11）

## 背景
- 住民票フォルダ書き込みでは、`C:E` / `C:F` に既存値がある行を再利用したい。
- ただし対象外列に値がある行まで再利用すると、他用途のデータを壊す。

## スコープ
- 住民票フォルダ書き込みは、対象列の既存値を無視して利用可否を判定する。
- `住民票フォルダ書き込みをC:Fにする` が OFF のときは `C:E`、ON のときは `C:F` を書き込み対象列とする。
- 判定は対象外列に値があるかどうかで行う。

## 制約
- 住民票通常書き込みや住民票シート2の挙動は変更しない。
- `C:F` ON 時の `F` 列は空文字で書き込む。
- 対象外列の値がある行は再利用しない。

## 受け入れ基準
- `C:E` モードでは、`C:E` に既存値があってもその行は利用できる。
- `C:F` モードでは、`F` を含めて既存値があってもその行は利用できる。
- 対象外列に値がある行は飛ばされる。
- 必要行数ぶん連続して対象外列が空いている最初のブロックが選ばれる。

## 非スコープ
- 他モードの行選定変更
- フォルダデータ構造の変更
- 対象外列に値がある行への強制上書き
