# ポモドーロタイマー機能削除仕様（2026-05-16）

## 範囲
- データ入力画面からポモドーロタイマーUIを削除する。
- ポモドーロタイマー用の状態、通知音、タイマー処理、永続化データ保存を削除する。
- 既存の入力、PDF、シート、漢字表示、保存済みリスト機能は維持する。

## 制約
- 過去のローカル保存データに `pomodoro` が残っていてもエラーにしない。
- ポモドーロ関連の既存仕様書は履歴として残し、今回の削除仕様を追加する。
- 有料APIや外部サービスは使用しない。

## 受け入れ条件
- 画面に `ポモドーロタイマー` パネルが表示されない。
- `pomodoro` 関連のReact state、effect、handler、アイコン import が残らない。
- リロード保持データに新規の `pomodoro` 保存を行わない。
- ビルドと既存テストが通る。

## 対象外
- PDF文字抽出/OCR、住所入力、Google Sheets連携の仕様変更。
