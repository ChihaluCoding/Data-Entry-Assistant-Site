# シートID取得失敗修正仕様（2026-04-09）

## 対象
- `src/app/components/DataEntryForm.tsx`
- `package.json`

## スコープ
- 固定シートURLからスプレッドシートIDを取得できず、シートタブ一覧取得や初期化が失敗する不具合を修正する。
- GoogleスプレッドシートURLの揺れに強いシートID抽出へ改善する。
- 抽出ロジックの回帰確認を追加する。

## 制約
- 既存のWebhook送信仕様、シートタブ選択UI、シート書き込み仕様は変更しない。
- シークレット値やURLはソースへハードコードしない。
- 既存の固定シートURL設定方式（`.env` と設定画面）は維持する。

## 受け入れ条件
- 固定シートURLが `docs.google.com/spreadsheets/d/{id}/...` 形式であれば、クエリや末尾形式に関係なくシートIDを取得できる。
- シートタブ一覧取得前に `activeSheetId` が空にならない。
- 既存URL形式で `npm run build` が成功する。
- シートID抽出の回帰確認スクリプトが成功する。

## 非対象
- Apps Script 側の修正。
- Googleスプレッドシートの共有権限変更。
- シートUIや文言の大幅変更。
