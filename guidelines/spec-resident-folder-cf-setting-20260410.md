# 仕様書: 住民票フォルダ書き込みの C:E / C:F 切替（2026-04-10）

## 背景
- 住民票シート1のフォルダ書き込みは通常 `C:E` を使うが、運用によっては `C:F` を使いたい場合がある。
- 複雑な再利用判定を入れると、住民票本体データとの干渉で挙動が分かりにくくなる。

## スコープ
- 設定画面に `住民票フォルダ書き込みをC:Fにする` チェックボックスを追加する。
- OFF 時は `C:E`、ON 時は `C:F` をフォルダ書き込み対象列として扱う。
- 行選定は書き込み対象列だけを見て、空いている連続ブロックを探す。

## 制約
- 住民票通常書き込みや住民票シート2の書き込み仕様は変更しない。
- OFF 時の既存 `C:E` 運用は維持する。
- ON 時の `F` 列は空文字で書き込む。
- 対象外列の値は、フォルダ書き込みの空き判定に使わない。

## 受け入れ基準
- 設定OFF時は `C:E` に書き込まれる。
- 設定ON時は `C:F` に書き込まれる。
- `C:E` モードでは `C:E` のいずれかに値がある行はスキップされる。
- `C:F` モードでは `C:F` のいずれかに値がある行はスキップされる。
- 対象外列に値があっても、対象列が空ならその行は利用できる。
- 複数行書き込みでは、必要行数ぶん連続して対象列が空いている最初のブロックへ書き込まれる。

## 非スコープ
- `F` 列に独自の新データを書き込む仕様追加
- 他モードの列マッピング変更
- 既存のフォルダ書き込み済み行を部分的にマージ更新する仕様
