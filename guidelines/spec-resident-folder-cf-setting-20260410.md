# 仕様書: 住民票フォルダ書き込みの C:E / C:F 切替（2026-04-10）

## 背景
- 住民票シート1のフォルダ書き込みは通常 `C:E` を使うが、運用によっては `C:F` を使いたい場合がある。
- あわせて、対象列に既存値があっても、その行を再利用して上書きできる必要がある。

## スコープ
- 設定画面に `住民票フォルダ書き込みをC:Fにする` チェックボックスを追加する。
- OFF 時は `C:E`、ON 時は `C:F` をフォルダ書き込み対象列として扱う。
- 行選定は、対象列に既存値があってもスキップしない。
- 行選定は、対象列以外に値がある行だけを除外する。

## 制約
- 住民票通常書き込みや住民票シート2の書き込み仕様は変更しない。
- OFF 時の既存 `C:E` 運用は維持する。
- ON 時の `F` 列は空文字で書き込む。

## 受け入れ基準
- 設定OFF時は `C:E` に書き込まれる。
- 設定ON時は `C:F` に書き込まれる。
- `C:E` または `C:F` に既存値がある行でも、対象外列が空なら再利用される。
- `A/B/G...` など対象外列に値がある行は、従来どおりスキップされる。

## 非スコープ
- `F` 列に独自の新データを書き込む仕様追加
- 他モードの列マッピング変更
