# 初回簡易ログイン撤去仕様（2026-04-09）

## 対象
- `src/app/components/DataEntryForm.tsx`
- `package.json`
- `package-lock.json`

## スコープ
- 初回利用時の簡易ログイン画面を廃止する。
- 固定認証情報 `admin / chihiro` を削除する。
- 認証済み状態の `localStorage` 依存を削除し、起動直後にツール本体を表示する。

## 制約
- 既存の入力、保存、設定、シート操作、PDF関連の機能は維持する。
- 新しい認証方式やサーバー処理は追加しない。
- 既存UIの主要導線は変更しない。

## 受け入れ条件
- 画面表示直後にログイン画面を挟まずツール本体が表示される。
- `DataEntryForm.tsx` 内に簡易ログイン用の固定資格情報が残らない。
- `npm run build` が成功する。

## 非対象
- 本格的な認証機構の追加。
- ログアウト機能。
- 権限制御やユーザー管理。
