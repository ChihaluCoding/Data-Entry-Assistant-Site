# 仕様書: 大字・字・小字のIME入力中は自動接頭語補正しない（2026-04-11）

## 背景
- 大字・字・小字の入力欄では `大字` / `字` / `小字` の自動付与をしている。
- しかし IME変換中にも補正をかけると、入力途中の1文字目で変換候補が崩れ、勝手に確定されたように見える。

## スコープ
- 基本モードと住民票モードの大字・字・小字欄では、IME変換中は入力値をそのまま保持する。
- IME変換が確定したタイミングでのみ、既存の `大字` / `字` / `小字` 自動付与を行う。

## 制約
- 自動接頭語付与の仕様自体は残す。
- 大字・字・小字以外の入力欄の挙動は変えない。
- 通常入力時の既存フォーマットは維持する。

## 受け入れ基準
- 大字欄で日本語入力の最初の1文字目を変換中に、候補が勝手に崩れない。
- 字欄、小字欄、および住民票モードの対応欄でも同様に入力途中で確定されない。
- IME確定後の最終値には `大字` / `字` / `小字` が先頭に正しく付く。

## 非スコープ
- 町域候補ロジックの変更
- 住所補完候補の検索条件変更
